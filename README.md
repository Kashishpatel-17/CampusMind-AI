# CampusMind AI - AI-Powered Academic Management and Student Employability Analysis

CampusMind AI is a multi-model AI framework designed to support academic management and student employability analysis. The project integrates AI-powered soft-skill analysis and ATS-based resume analysis to help evaluate communication-related indicators and provide insights into student career readiness.

## 🚀 Key Features
- Soft Skill Analysis: Uses speech transcription and AI-based analysis to assess communication-related indicators.
- ATS Resume Analysis: Analyzes resumes to support resume evaluation and employability assessment.
- Speech Transcription: Integrates OpenAI Whisper for speech-to-text processing.
- Natural Language Processing: Uses NLP techniques to process and analyze textual information.
- Computer Vision: Incorporates MediaPipe for relevant visual analysis tasks.
- Academic Management: Supports academic management-related functionality within the project framework.

## 🛠️ Technologies Used
- Programming Languages: Python, JavaScript
- Backend: Node.js, FastAPI
- Database: PostgreSQL
- Speech Processing: OpenAI Whisper
- Natural Language Processing: spaCy
- Computer Vision: MediaPipe

## 🏗️ Project Overview
CampusMind AI combines multiple AI technologies to explore academic management and student employability analysis in one framework. Its modules focus on speech transcription, communication-related indicators, soft-skill analysis, and resume evaluation.

## 🎯 Project Objectives
- Explore AI-driven approaches to student employability analysis.
- Support the analysis of communication-related indicators.
- Integrate resume analysis into an employability-focused framework.
- Combine multiple AI technologies in an academic project.
